DiRT Rally 2.0 VR Grass and Menu Colour Fix v1.2.0

Fixes washed-out VR menus by removing an extra 1/2.2 gamma operation from two exact-hash UI pixel shaders. All confirmed grass fixes from v1.1.0 are retained.

Confirmed working with CrossOver Preview, D3DMetal, MoltenVR and OpenComposite. Both menu shaders were matched and the visual result was confirmed in-game. No diagnostic logging, GPU captures or test modes.

Install version.dll beside dirtrally2.exe, replacing the previous grass-fix DLL. Keep the existing Native, then Builtin version override. OpenComposite is a separate component.

If menus are clipped, keep the VR desktop/menu resolution at 1920x1080 in hardware_settings_config_vr.xml. This is a separate configuration fix.
